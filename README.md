# Python System Info 

A Windows system information utility built with Python. This project started as a simple command-line program and was expanded into a graphical desktop application. 

## Features 
-Displays computer name, Identifies the operating system, Shows available disk space, provides an interactive graphical interface, runs as a windows desktop application

## Technologies Used

-Python
-Tkinter (GUI)
-Python standard library
-PyInstaller
-Git and GitHub

## How to Run

### Command-Line Version

Run: 
     py system_info.py
### Desktop GUI Version

Run: 
    py gui.py
Click "Check My Computer" to display your system information
The GUI can also be packaged as a Windows executable using PyInstaller.
